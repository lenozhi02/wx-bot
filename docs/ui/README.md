# WX-BOT Web UI 设计文档

## 文档规范

每个 Phase 包含以下文档：
- `design.md` — 设计文档（架构、接口、数据流）
- `changelog.md` — 变更记录（新增/修改/删除的文件）
- `test-report.md` — 测试报告（测试用例、结果）
